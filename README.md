# Ventura Semijoias

Site vitrine de página única desenvolvido por ROMERO ADS&WEB.

## Publicação

Em Settings → Pages, selecione Deploy from a branch, branch main e pasta /(root).

## Arquivos

- index.html: página do site.
- assets/: imagens otimizadas em WebP.

O formulário de pré-aprovação abre no Microsoft Forms.
